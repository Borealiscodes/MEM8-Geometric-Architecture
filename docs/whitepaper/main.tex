\begin{abstract}
This document provides a formal geometric specification of the MEM8-Geometric-
Architecture, a mathematically grounded interpretation of the MEM|8 cognitive-
compute ecosystem. The architecture expresses memory, semantics, salience,
routing, stability, and cognitive loops through geometric operators, curvature,
drift, geodesics, and membrane evaluation.
\end{abstract}
